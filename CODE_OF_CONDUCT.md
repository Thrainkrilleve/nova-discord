# Code of Conduct

Be respectful in issues, pull requests, and discussions. Harassment, hate speech, and personal attacks are not welcome.

Nova remembers people and can act in Discord. Do not post other people's conversations, memories, or personal data here. Do not use this project to ask for help stealing data, impersonating someone, or bypassing another community's rules.

Do not post Discord tokens, `.env` files, API keys, or database dumps. Redact logs before you share them.

Report unacceptable behavior to the repository owner through GitHub. For a security vulnerability, use [SECURITY.md](SECURITY.md) instead of a public issue.
